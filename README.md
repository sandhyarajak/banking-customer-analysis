📊  banking-customer-analysis

📌 Project Overview

This project analyzes customer banking behavior using Python, SQL, and Power BI.
The objective is to clean, explore, and visualize customer data to extract meaningful insights for better decision-making.

🛠️ Tools & Technologies
1. 🐍 Python (Pandas, NumPy, Matplotlib, Seaborn)
2. 🗄️ MySQL
3. 📊 Power BI
4. 💻 Git & GitHub

📈 Key Insights

1. Customers with high bank deposits also maintain high balances in:
 --Checking Accounts
 --Saving Accounts
 --Foreign Currency Accounts
2. Strong positive correlation between financial assets
3. Income segmentation helps in identifying different customer groups


▶️ How to Run the Project

 1. Clone the repository:

2. Install Required Libraries
